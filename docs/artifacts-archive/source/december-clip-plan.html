Irondost December Clip Plan

Seven new clips built only from images already in ~/Downloads/Irondost-Clip-Assets, plus a posting calendar that mixes them with the five reels already rendered in docs/marketing/december-2026-pack/reels. Every file name below matches the library, so you can search for it directly in your editor's media bin. Prices are from the live rate card used in the existing reels.

House rules for every clip

Hook in the first 1.5 s

Text on screen from frame one. No logo intro on social clips.

Same end card

Last 3–4 s: logo, Call/WhatsApp number, Play Store and App Store QR. Reuse the end card from the existing reels.

Safe area for 9:16

Keep text inside the middle 1080×1420. Instagram covers the top 220 px and bottom 280 px.

Motion

Stills get a slow 1.14→1.0 zoom per shot. Cuts on the beat, 0.3 s wipes only for before/after.

Truthful copy

Only real prices, slots and areas. No review counts or order numbers until there are real ones.
