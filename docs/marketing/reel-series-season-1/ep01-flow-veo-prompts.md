# Dost Undi Ga! · Ep 1 · Kondalu · Google Flow (Veo) prompts
This is Season 1 v3, Episode 1, retimed for Google Flow. Veo makes 8-second clips, so each 10-second v3 clip is now **one 8-second shot**. All dialogue lands inside those 8 seconds, so no Extend step is needed. The reel is 4 × 8 s = 32 s, plus the 4-second end card.

## Flow settings (every clip)
- Mode: **Ingredients to Video** · Model: **Veo (highest quality)** · Aspect: **9:16** · Outputs: **2**
- Ingredients: the 3 images on the clip's **Ingredients** line (Flow takes 3 at most). They are in `videos/dost-undi-ga/refs/`.
- Paste the whole prompt block. Flow has no negative box, so the AVOID line is part of the prompt.
- Keep a take only if: the faces match the refs, each line is said once by the right lips, there is no music and no AI-drawn text. If a voice is wrong, keep the picture and dub the line.
- Save as `videos/dost-undi-ga/ep01/E1-C{n}.mp4`. Add the captions, hook text, logo and end card in CapCut.
